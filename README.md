# Omar Osama — Link Hub

A static, mobile-first personal link hub.

## Files
- `index.html` — page structure, SEO metadata and structured data
- `style.css` — responsive visual system and dark theme
- `script.js` — theme toggle and current year
- `assets/omar-osama.webp` — optimized portrait
- `favicon.svg` — custom favicon

## Deploy
Upload the contents of this folder to the root of a GitHub Pages repository, or place the folder at `/links/` in an existing site. If placed at `/links/`, the URL will be `https://your-domain/links/`.

No analytics, cookies, forms, backend, or third-party scripts are used.
